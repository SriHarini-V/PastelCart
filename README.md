\# PastelCart



PastelCart is a modern e-commerce web application built using React and Vite.



\## Features



\* User-friendly product browsing

\* Product details

\* Shopping cart

\* Checkout

\* User authentication

\* Orders management

\* Responsive interface

\* REST API integration



\## Technologies Used



\* React

\* Vite

\* JavaScript

\* HTML

\* CSS

\* REST API



\## Installation



Clone the repository:



```bash

git clone https://github.com/SriHarini-V/PastelCart.git

```



Go to the project directory:



```bash

cd PastelCart

```



Install dependencies:



```bash

npm install

```



Start the development server:



```bash

npm run dev

```



The application will be available at:



```text

http://localhost:5173

```



\## Build for Production



```bash

npm run build

```



\## Preview Production Build



```bash

npm run preview

```
